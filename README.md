### Proyectos

**[FigmaToRoblox](https://github.com/UiUyHerrera/FigmaToRoblox)** · JavaScript, Node.js, Luau\
Puente entre Figma y Roblox Studio. Diseñás una pantalla en Figma, copiás un código de seis letras y en Studio aparece como UI nativa de Roblox, con botones, paneles, pestañas y animaciones. Un servidor local guarda el diseño y sube las imágenes a Roblox por Open Cloud.

**[Reservini](https://github.com/UiUyHerrera/reservini)** · Python, Flask, SQLAlchemy, PostgreSQL\
Reservas para negocios chicos. El dueño carga sus servicios y horarios, comparte un link y los clientes reservan solos. No deja tomar dos veces la misma hora, manda confirmación y recordatorio por mail, y los tests corren en GitHub Actions.

**[ecommerce-rest-api](https://github.com/UiUyHerrera/ecommerce-rest-api)** · TypeScript, Express, Prisma, PostgreSQL\
API de una tienda: registro con JWT, roles, productos con stock y pedidos que se arman dentro de una transacción. Está documentada con OpenAPI y los tests de integración corren contra un PostgreSQL en Docker.

**[mpeasy](https://github.com/UiUyHerrera/yt-mp4)** · JavaScript, Python\
Extensión de navegador para bajar audio y video. La extensión le pasa cada pedido por native messaging a un programa local en Python que usa yt-dlp y ffmpeg. Cuando cambio la versión en el manifiesto, GitHub Actions arma el release solo.

**[AimGearZ](https://aimgearz.cl)** · Shopify, Liquid\
Mi tienda de periféricos gaming en Chile. Programé el tema entero: catálogo, buscador, carrito y las secciones propias.
